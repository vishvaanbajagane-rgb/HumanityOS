# 🌍 HumanityOS

> **One Intelligent Platform for Every Human Need**

HumanityOS is a next-generation AI-powered humanitarian platform that connects underserved communities with essential services through a single intelligent ecosystem. Built using modern web technologies, Artificial Intelligence, and cloud infrastructure, HumanityOS helps people worldwide access healthcare, education, emergency assistance, employment, government welfare programs, NGOs, volunteers, and community resources in multiple languages.

The platform is designed to reduce barriers to information and provide personalized assistance through AI, enabling faster access to life-changing resources regardless of language, location, or economic background.

---

## 🌎 Vision

To build the world's most intelligent humanitarian platform that empowers every individual with equal access to opportunities, support, and essential services through Artificial Intelligence.

---

## 🎯 Mission

Our mission is to eliminate the information gap between people in need and organizations that can help them by providing one centralized AI-powered platform that is accessible, multilingual, inclusive, and available worldwide.

# 🔐 Authentication Flow

1. User opens HumanityOS.
2. Login page is displayed.
3. User signs in using Google or Email.
4. Firebase authenticates the user.
5. User information is securely stored in Supabase.
6. Authentication session is maintained.
7. User is redirected to the Home Page instantly.
8. Protected routes ensure secure access.
